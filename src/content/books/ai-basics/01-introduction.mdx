# 생성형 AI의 출발점

생성형 AI는 학습 과정에서 익힌 데이터의 패턴을 바탕으로 새로운 텍스트, 이미지, 코드 등의 출력을 만들어내는 모델을 말합니다.

단순히 **정답을 데이터베이스에서 찾는 검색**과는 다릅니다. 언어 모델은 지금까지 입력된 토큰을 바탕으로 다음에 올 토큰의 확률 분포를 계산하고, 그 분포에 따라 출력을 이어갑니다.

## 학습과 추론은 구분해서 생각하기

| 구분 | 학습(training) | 추론(inference) |
| --- | --- | --- |
| 목적 | 모델의 파라미터 갱신 | 학습된 모델로 출력 생성 |
| 입력 | 학습용 데이터 | 사용자의 프롬프트 및 문맥 |
| 주요 비용 | 대규모 연산과 시간 | 요청별 토큰 처리와 메모리 |

> **핵심 개념**: 모델이 지금 답변을 생성한다고 해서, 그 대화가 즉시 모델 파라미터를 변경하는 것은 아닙니다.
