# 프롬프트를 구조화하기

막연한 지시보다, 목표와 조건이 구체적인 지시가 대개 결과를 평가하고 개선하기 쉽습니다.

## 네 가지 기본 요소

1. **목표**: 무엇을 하길 원하는가?
2. **맥락**: 어떤 정보와 상황을 고려해야 하는가?
3. **제약**: 반드시 지킬 사항과 제외할 사항은 무엇인가?
4. **출력 형식**: 표, JSON, 단계별 설명 등 어떤 형태가 필요한가?

```text
목표: 다음 기술 문서를 한국어로 요약한다.
맥락: 대상 독자는 백엔드 개발자다.
제약: 확인되지 않은 기능은 추측하지 않는다.
출력: 핵심 요약 3문단 + 주요 옵션 표.
```
